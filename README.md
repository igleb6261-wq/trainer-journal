# Журнал тренера

Мобильное приложение для ведения клиентов: анкета, программы тренировок, проведение тренировки с подходами/весом/повторениями/запасом, история со сводкой изменений, замеры, фото «до / после».

Работает полностью на телефоне, без сервера и интернета. Данные хранятся только в телефоне — делай резервную копию в «Настройках».

**Открыть:** https://igleb6261-wq.github.io/trainer-journal/

## Установка на телефон
- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран "Домой"».
- **Android:** открыть ссылку в Chrome → ⋮ → «Установить приложение».

## Для разработки
```
npm install
npm run dev     # локальный запуск
npm run build   # сборка в dist/
```
Стек: React + TypeScript + Vite, Tailwind CSS, Dexie (IndexedDB), vite-plugin-pwa. Публикация — GitHub Actions → GitHub Pages при каждом изменении в ветке main.
